## 3. Headline findings

- The teacher's input and prompts had to be adapted. Window AUPRC moves from zero-shot to learned prompts as
  follows: Daphnet 0.123 → 0.531, 3W 0.771 → 0.974, MetroPT 0.037 → 0.989 (MetroPT: 2 easy test events, see
  audit). On Credit Card every teacher stays weak (best 0.217).
- Distillation vs. the identical labels-only GRU (same seeds):
  - MetroPT, base training: +0.124 window / +0.365 point AUPRC (3/3 seeds).
  - MetroPT, both models regularized: +0.080 / +0.061 (3/3 seeds). The larger base-training gain mostly
    reflected an overfitting baseline.
  - Neutral on Credit Card, 3W and Daphnet.
- Out of sample (label-free series, deployed models): on MetroPT both students find 10/12 hidden real failures;
  the distilled student has higher point AUPRC (0.717 vs 0.672) and event F1 (0.546 vs 0.424). With the base
  checkpoints it was 10/12 vs 0/12.
- Overfitting (`OVERFITTING.md`, deployed models): none on Credit Card or 3W. MetroPT train−test gap: 0.14
  (labels only) and 0.10 (KD). Daphnet: a subject-shift gap of about 0.2 for every model, including the teacher.
- Novelty components all work as specified (`NOVELTY_CHECKS.md`).

## 4. Generalisation study (regularized training)

Weight EMA, gain/noise augmentation, learning rate 1e-3, dropout 0.3, patience 6
(`experiments/benchmark_v2_regularized/`, `GENERALISATION.md`). It lowers seed variance and the train−test gap
where the base models overfit:
- Daphnet KD window AUPRC 0.592 → 0.655, std 0.068 → 0.030;
- MetroPT labels-only gap 0.40 → 0.14.

Validation separates the configurations only weakly (near-ties; MetroPT validation is saturated). The deployed
checkpoints follow the pre-set validation rule: regularized for Daphnet (both), 3W (KD) and MetroPT (both); base
otherwise. The main ablation tables use the base configuration throughout.
